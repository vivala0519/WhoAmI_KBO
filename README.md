# 2026 야구 선수 맞히기

앱인토스용 하루 한 문제 선수 추리 게임이다. 현재 `src/players.json`은 제공받은 2026 KBO 선수 자료에서 **등번호와 원화 환산 연봉이 있는 상위 250명**을 선정한 로컬 미리보기다. 1군 출전 여부와 앱 배포 권리는 아직 확인되지 않았다.

## 로컬 실행

```powershell
npm ci
npm run dev
```

모바일 폭에서 `http://127.0.0.1:5176/`을 연다. 타입 검사와 웹 빌드는 `npm run build`, 앱인토스 번들은 `npm run build:toss`로 만든다. 실제 등록·업로드는 하지 않았다.

## 실제 데이터 준비

[DATA_SOURCES.md](./DATA_SOURCES.md)에 두 CSV의 결합·선정 기준과 검증 결과를 기록했다. [선정 보고서](./data/top250-selection-report.json)에는 250명 전체 순위와 원본 파일 해시가 있다. `scripts/select-kbo-top250.mjs`로 같은 입력에서 결과를 재현할 수 있다. 정답 일정은 공개 전 확정하고 공개한 날짜의 정답은 변경하지 않는다.

제공 CSV의 출처는 KBO 선수 조회·상세 페이지다. [KBO 이용약관](https://www.koreabaseball.com/Etc/Policy.aspx)은 허가 없는 대량 자동 수집과 수집 데이터 재배포를 제한하므로 이 번들은 업로드하지 않았다. 공개 전에는 광고가 있는 미니앱에서의 저장·가공·배포 권한과 2026 1군 출전 여부를 확인한다.

## 앱 설정

- UI는 형제 프로젝트 `WhoAmI`의 화면 구조·타이포·라이트/다크 테마를 기준으로 구성했다. 첨부 야구공을 사용하는 파티클 효과는 [파티클 안내](./docs/particle-ball.md)를 참고한다.

- `apps-in-toss.config.ts`의 `appName: "whoamikbo"`는 새 앱을 위한 임시 식별자다. 콘솔에 등록한 식별자와 맞춘다.
- 개발 중 보상형 광고는 공식 테스트 ID를 사용한다. 운영용 그룹 ID는 `.env.example`을 참고해 `VITE_TOSS_REWARDED_AD_GROUP_ID`로 설정한다. 새 앱의 보상 단위는 `기회`, 수량은 `1`이다.
- 진행 상태, 기록, 도감과 테마는 이 앱 전용 브라우저 로컬 저장소 키를 사용한다. 기기 간 동기화는 없다.
- 선수 사진과 구단 로고는 사용하지 않는다.
